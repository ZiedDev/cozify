# Cozify Sound Effects Directory

Place your audio files (`.mp3`, `.wav`, `.ogg`, or `.m4a`) in this folder.
They are served directly by the app from the root `/sounds/...` URL path.

## Standard Sound Effect Files

| Filename | Sound Effect | Trigger |
| :--- | :--- | :--- |
| `pomo-start.mp3` | `pomoStart` | Starting or resuming pomodoro / break timer |
| `pomo-pause.mp3` | `pomoPause` | Pausing the timer |
| `pomo-end.mp3` | `pomoEnd` | Timer reaching 0 (end of focus or break cycle) |
| `notification.mp3` | `notification` | Notifications and alert toasts |
| `achievement.mp3` | `achievement` | Unlocking an achievement milestone |
| `task-complete.mp3` | `taskComplete` | Checking off a task in the to-do list |
